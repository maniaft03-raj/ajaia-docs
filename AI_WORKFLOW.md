AI Workflow
I used Cluely for implementation guidance, scaffolding, debugging,
test design, and deployment instructions.
AI accelerated the React/Tiptap editor, FastAPI endpoints,
SQLite storage, permission checks, and Docker deployment setup.
The implementation evolved from browser-local storage to a
server-backed database. Debugging included incorrect unsaved-change
notifications and deployed editor editability.
Verification included manual document, formatting, import, and
sharing checks, a passing automated backend permissions test,
and a successful frontend production build.
The automated test covers unauthorized access, viewer write
restrictions, editor saves, owner visibility, and access revocation.
AI-generated changes required inspection and execution.
An active deployment alone did not establish that editing worked;
the deployed editor required additional debugging and manual checking.
